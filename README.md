WeIntern Data Science Internship - Week 1 Project

📌Week Number and Objective

 Week: Week 1

 
 Objective: The goal is to clean data, analyze key performance indicators (KPIs), and visualize sales trends.

 Dataset Description
 
 Dataset Name:'ecommerce_data.csv'
 
 Description:Contains e-commerce transaction details including order IDs,product categories,quantities sold,prices,payment methods,and timestamps.
 
 🛠️ Tools & Technologies Used
 
Platform:Google Colab

Language:Python

Libraries:Pandas & Matplotlib (for Data Analysis & Visualization)

 
 
 📊 Key Tasks Completed
1. Data Cleaning:* Handled missing values and duplicates in ecommerce_data.csv.
2. Sales & KPI Analysis:* Calculated Total Revenue, Total Orders, Average Order Value, Total Units Sold, Top Category, and Best Product.
3. Data Visualization:* Generated Bar Charts, Line Charts, and Pie Charts to represent sales trends and payment distributions.
